# 地脉智防｜地质灾害主动防控平台

地脉智防以湖北省宜昌市为应用区域，将斜坡单元风险数据、地理空间可视化、专业知识检索与多智能体业务处置组织在同一平台中，覆盖风险查询、事件建档、辅助研判、处置建议、任务反馈与复盘归档。

本仓库包含运行源码、Docker容器配置、宜昌本地地理数据、风险结果时片及秭归市事件处置资料。系统可在Windows计算机上部署；首次部署需要联网下载运行依赖。风险数据与事件资料可在无外部模型密钥的情况下访问，但专业问答的模型生成能力需要单独配置。

## 一、部署与启动

环境要求：Windows 10/11、Docker Desktop（Linux容器模式），建议16GB及以上内存，并为镜像构建、依赖与数据预留足够磁盘空间。

1. 下载本仓库的**完整源码**并解压至英文路径，例如`D:\DiMai`。请保留`data`和`frontend/geo-guard-fe/public/geo/yichang`目录；不可仅复制前端代码。
2. 安装并启动Docker Desktop，等待引擎显示运行中。
3. 双击仓库根目录的**`启动地脉智防.bat`**，等待容器构建和八项部署检查完成。第一次启动需要联网下载镜像和软件依赖，所需时间与网络速度有关。
4. 浏览器会自动打开风险评价地图。首次启动自动生成独立本机登录密码，账号为`admin`；密码保存于根目录的`本机登录信息.txt`，也可在同一文件中查看访问地址。
5. 测试结束后双击`停止地脉智防.bat`。数据库和知识库文件保留，下次启动可继续使用。

如需重新检查服务状态，双击`检查地脉智防.bat`。如果检查失败，在仓库目录运行`docker compose ps`和`docker compose logs --tail=100`查看原因。

若需逐接口核验协同处置流程，双击`验收协同处置流程.bat`并按提示确认。流程将在本地创建新的秭归市事件记录，核验两阶段监测研判、方案审核、任务反馈、四项任务复核、报告归档、持久化回读与DOCX下载。随包资料不代表实时现场数据或正式行政处置记录。

**安装说明：**请从正式提交的仓库完整下载。`git clone`与GitHub的源码ZIP均可使用，但必须确保大体积地形和风险数据完整下载。若从其他位置取得单独的升级覆盖包，应先安装到同一仓库根目录，再执行上面的启动步骤。

## 三、业务流程检查

1. 打开风险评价地图，切换县区和风险显示，核对本地地理图层是否出现。
2. 打开动态风险一张图，查看平台提供的风险时片和分区结果。该页面读取已随包交付的历史计算结果，不表示当日实时气象预报。
3. 进入协同处置中心，建立秭归市事件，依次查看监测研判、生成处置建议、记录审核、异常阶段反馈、恢复阶段研判及反馈、任务复核，并生成和下载DOCX复盘报告。
4. 刷新页面或重启容器，重新进入该事件，检查任务、反馈与报告是否从持久化数据库恢复。
5. 进入知识库管理页面，检查文档管理功能；如果已配置模型服务，可继续评测专业问答质量。

**随包资料范围：**秭归市事件处置流程包含随软件交付的现场、监测、人员、审核及反馈资料。相关操作记录保存在本地数据库，不等同于实时设备上报、应急部门正式审批或实际险情处置。实际预警和处置结论应以现场核查、接入设备数据及正式审核记录为准。

## 四、随仓库提供的模块

| 目录 | 用途 |
|---|---|
| `frontend/geo-guard-fe` | 地脉智防业务前端、风险地图与协同处置中心 |
| `frontend/geo-guard-fe/public/geo/yichang` | 宜昌本地行政边界、路网、水系和地形瓦片 |
| `ai/p6-service`、`data/p6` | P6风险结果、时片数据库与查询接口 |
| `ai/geo-agent-graph`、`data/yichang-scenario` | 多智能体服务编排、秭归市事件记录与处置流程资料 |
| `ai/geo_rag`、`frontend/geo_rag` | 知识库API与知识库管理界面 |
| `backend/geo-guard-backend/local-auth-service` | 本地账号登录和会话服务 |
| `compose.yaml` | 六个容器的构建、连接与持久化数据卷 |

### 服务与持久化

- `5174`：风险地图、业务系统前端；`5175`：知识库管理；`8011`：多智能体业务接口（均限制绑定到本机回环地址）。
- `geo-rag-data`数据卷保存知识库内容，`scenario-data`保存业务事件与报告。停止容器不会自动删除这两个数据卷。
- 使用`docker compose down --volumes`会清理数据卷，**请勿将其用于普通停止操作**。
- 登录凭据由本机生成于`.env`和`本机登录信息.txt`，不要上传到公开仓库。

## 五、计算结果与对外依赖

P6服务对包内结果执行读取与查询；仓库现有入口不负责自动重新训练滑坡易发性模型或在启动时重算全市降雨风险。若需要展示新雨量驱动的更新结果，必须提供对应的数据更新流程、模型及计算资源，并另行验收。

大模型问答、部分智能体及真实设备接入涉及外部模型服务、知识库内容、网络接口和授权凭据。未完成配置时，不能将相关结果解释为已接入的实时能力。完成本地部署后，可使用本地地图、风险时片和秭归市事件处置流程。

地理数据及依赖软件遵守对应许可。水系数据按OpenStreetMap ODbL要求署名；地形数据来源与署名信息保存在地形配置文件中，其他第三方说明见`THIRD_PARTY_NOTICES.md`。

本仓库为**地脉智防完整源码交付版本**，实际可用能力以部署检查、外部服务配置及上述数据范围说明为准。
